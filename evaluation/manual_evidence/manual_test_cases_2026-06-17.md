## 1. Excel Mshta Persistence

Slug: `excel_mshta_persistence`

Package ID: `8a921198c396`

Summary: A fake invoice Excel attachment launches mshta, retrieves a remote payload, creates Registry Run Key persistence, then connects to unknown HTTPS domains.

Telemetry: `edr_process`, `edr_registry`, `dns`, `proxy`, `firewall`

MITRE:

- `T1218.005 - Mshta`
- `T1105 - Ingress Tool Transfer`
- `T1547.001 - Registry Run Keys / Startup Folder`
- `T1071.001 - Web Protocols`

Queries:

- `Process Registry Network Hunt`
- `Registry Runkey Hunt`

Checklist excerpt:

- Find hosts where `excel.exe` spawned `mshta.exe`.
- Check whether `mshta.exe` made outbound web requests.
- Check Registry Run Key creation on the same hosts.
- Correlate process, registry, and network events within 24 hours.

Escalation: Escalate when the same host shows Office-to-mshta process chain plus persistence or suspicious network activity.

## 2. DNS Tunneling TXT

Summary: A threat advisory reports malware using high-volume DNS TXT queries with encoded-looking subdomains for command and data transfer.

Telemetry: `dns`, `edr_process`, `proxy`, `firewall`

MITRE:

- `T1071.004 - DNS`
- `T1041 - Exfiltration Over C2 Channel`
- `T1059.001 - PowerShell`
- `T1105 - Ingress Tool Transfer`

Queries:

- `Dns Tunneling Hunt`
- `Encoded Powershell Hunt`

Checklist excerpt:

- Find hosts with high TXT query count.
- Search for long or high-entropy subdomains.
- Group by host and base domain.
- Correlate with endpoint process telemetry.

Escalation: Escalate when one host generates abnormal TXT volume to unknown domains and endpoint context is missing or suspicious.

## 3. Password Spray Many Users

Slug: `password_spray_many_users`

Package ID: `54589f282d7c`

Summary: Many users receive failed login attempts from the same source, suggesting password spraying.

Telemetry: `auth`, `cloud_audit`, `edr_process`, `edr_registry`, `dns`, `proxy`, `firewall`

MITRE:

- `T1110.003 - Password Spraying`
- `T1110 - Brute Force`
- `T1078 - Valid Accounts`
- `T1098 - Account Manipulation`

Queries: none generated because the MVP does not yet include a dedicated password spray query template.

Checklist excerpt:

- Search relevant telemetry for unusual authentication patterns.
- Review whether the source IP or device is outside the user's baseline.
- Correlate activity by user, host, source IP, destination, and time window.
- Confirm whether the behavior is expected business activity before escalation.

Escalation: Escalate when password spray against many users is confirmed on a real user, host, workload, or production asset and the behavior cannot be explained by approved business activity.

## 5. GitHub OAuth Repository Access Holdout

Slug: `github_oauth_repo_access_holdout`

Package ID: `0b6ee0889764`

Summary: A developer receives a public issue message asking them to install a GitHub productivity OAuth app. After authorization, the app accesses private repositories, reads repository secrets metadata, creates a deploy key, and the developer logs in from a new IP address.

Telemetry: `cloud_audit`, `auth`, `proxy`

MITRE:

- `T1528 - Steal Application Access Token`
- `T1098 - Account Manipulation`
- `T1552 - Unsecured Credentials`
- `T1530 - Data from Cloud Storage Object`
- `T1078 - Valid Accounts`

Queries:

- `Developer Oauth Repo Access Hunt`
- `Oauth Consent Hunt`
- `Saas Oauth File Export Hunt`

Checklist excerpt:

- Review GitHub/GitLab OAuth app authorization and granted repository scopes.
- Check which private repositories were accessed, cloned, or enumerated by the app.
- Review deploy key creation events and confirm whether each key is approved.
- Check repository secrets metadata access and related workflow or token activity.
- Correlate developer login source IP, device, and session context with app activity.

Escalation: Escalate when the app is unapproved, has broad read/export permissions, accesses sensitive data, or the related user login/session is suspicious.
