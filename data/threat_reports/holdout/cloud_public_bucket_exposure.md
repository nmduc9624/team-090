# Holdout Report: Cloud Storage Bucket Made Public

## Summary
A cloud storage bucket or object ACL is changed to allow public access, followed by unusual data access from a new identity.

## Observed Behaviors
- cloud control plane setting changes unexpectedly
- actor, key, or workload is unusual for the action
- sensitive resource access or privilege expansion follows

## Indicators
- domains: none
- ips: none
- hashes: none
- files: none
- processes: none
- registry_keys: none
